# Public proposal summary

IEEE Radar Challenge 2027 | PA College of Engineering, Mangaluru, India

The proposed USRP-based FMCW radar research investigates laboratory ranging and motion sensing for search-and-rescue research. Through-barrier and micro-motion objectives remain exploratory. The proposal lists an entry-tier B-Series USRP and GNU Radio/UHD with Python as provisional choices. Neither the final hardware nor the software selection has been confirmed. Faculty advisor approval has been received according to the team; licensing approval remains pending. All testing is subject to faculty approval, RF compliance and privacy safeguards. Expected deliverables include documentation, verified measurements, a limitations report and a demonstration. No numerical performance is claimed at this stage. The original submission document is retained privately because it contains contact information.
