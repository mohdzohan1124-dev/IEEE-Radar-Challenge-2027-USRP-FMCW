# Public proposal summary

IEEE Radar Challenge 2027 | PA College of Engineering, Mangaluru, India

The proposed USRP-based FMCW radar research investigates laboratory ranging and motion sensing for search-and-rescue research. Through-barrier and micro-motion objectives remain exploratory. The preferred platform is an entry-tier B-Series USRP, subject to allocation; GNU Radio/UHD and Python are the proposed software choices. All testing is subject to faculty approval, RF compliance and privacy safeguards. Expected deliverables include documentation, verified measurements, a limitations report and a demonstration. No numerical performance is claimed at this stage. The original submission document is retained privately because it contains contact information.
