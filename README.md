# IEEE Radar Challenge 2027 — USRP FMCW Radar

**Institution:** PA College of Engineering, Mangaluru, India

**Status:** Proposal stage; no validated implementation or measured performance yet.

## Overview
The project proposes controlled laboratory research into software-defined radar ranging and motion sensing, motivated by search and rescue. Through-barrier and micro-motion studies are exploratory objectives. The proposed platform is an entry-tier B-Series USRP, subject to allocation, with GNU Radio/UHD and Python as the preferred software environment.
